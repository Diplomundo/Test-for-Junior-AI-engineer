# 📊 AI Financial Assistant

Прототип AI-ассистента для анализа финансовых данных компании за 2005–2024 гг. Загружает данные, рассчитывает ключевые метрики и отвечает на вопросы пользователя с помощью LLM (Claude, Anthropic API).

## Установка и запуск

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/Diplomundo/Test-for-Junior-AI-engineer.git
cd Test-for-Junior-AI-engineer
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
```

### 2. API-ключ

Создайте файл `.env` в корне проекта:

```
ANTHROPIC_API_KEY=sk-ant-your-key-here
```

Ключ можно получить на [console.anthropic.com](https://console.anthropic.com/).

### 3. Запуск

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## Архитектура

Решение состоит из трёх модулей:

### 1. Модуль обработки данных (pandas)
- Загрузка `financial_data.csv`
- Расчёт метрик: рост выручки (YoY), операционная маржа, чистая маржа
- Формирование текстового контекста для передачи в LLM

### 2. Модуль LLM-интеграции (Anthropic API)
- Модель: Claude Sonnet (`claude-sonnet-4-6`)
- Системный промпт содержит строгие правила: модель использует только предоставленные данные, объясняет расчёты, не придумывает числа
- `temperature=0.2` — минимизация галлюцинаций при работе с числами
- Все 20 строк данных с рассчитанными метриками передаются в контексте промпта (RAG/векторная БД избыточны для такого объёма)

### 3. Интерфейс (Streamlit)
- Чат-интерфейс с историей сообщений (`st.chat_message` + `st.session_state`)
- Кнопки с примерами вопросов для быстрого старта
- Боковая панель: интерактивные графики Plotly (выручка и прибыль, рост выручки YoY) и таблица с метриками

```
Streamlit UI (чат + графики Plotly)
        │
        ▼
Обработка данных (pandas)
  • financial_data.csv → DataFrame
  • Расчёт: revenue_growth, operating_margin, net_margin
  • Формирование текстового контекста
        │
        ▼
Anthropic API (Claude Sonnet)
  • Системный промпт + данные + вопрос → ответ
```

### Ключевые решения
- **Ключевые финансовые метрики рассчитываются в Python**, после чего передаются в LLM для текстовой интерпретации.
- **Данные передаются целиком в контексте** — 20 строк легко помещаются в контекстное окно, RAG здесь избыточен
- **Низкая temperature** — точность важнее креативности в финансовом анализе

## Примеры запросов и ответов

### 1. Аналитический вопрос

**Вопрос:** В каком году был самый быстрый рост выручки?

**Ответ:** Самый быстрый рост выручки наблюдался в 2006 году — примерно 29.2%. Выручка выросла со $120,000 (2005) до $155,000 (2006), абсолютный прирост составил $35,000.

### 2. Анализ трендов

**Вопрос:** Как изменялась прибыльность компании со временем?

**Ответ:** Прибыльность компании оставалась стабильной на протяжении всего периода: операционная маржа держалась на уровне ~25%, чистая маржа — также около 25%. Это говорит об устойчивой бизнес-модели с пропорциональным ростом расходов и выручки.

### 3. Объяснение метрики

**Вопрос:** Объясните динамику операционной маржи компании.

**Ответ:** Операционная маржа = (Выручка − COGS − Операционные расходы) / Выручка. За период 2005–2024 она колеблется в диапазоне 24.3–25.0%, то есть на каждый заработанный доллар компания сохраняет ~25 центов операционной прибыли. Отсутствие значимых колебаний указывает на пропорциональный рост расходов вместе с выручкой.

### 4. Сравнительный анализ

**Вопрос:** Сравните показатели 2005 и 2024 года.

**Ответ:** За 20 лет выручка выросла с $120,000 до $3,650,000 (~30x), чистая прибыль — с $30,000 до $912,000 (~30x). При этом маржинальность практически не изменилась (~25%), что говорит о масштабировании бизнеса с сохранением эффективности.
